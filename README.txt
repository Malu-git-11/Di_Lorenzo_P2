DI LORENZO ADVOCACIA — PROJETO P2

ESTRUTURA
- index.html: tela Fale Conosco
- quem-somos.html: tela Quem Somos
- faq.html: tela Perguntas Frequentes
- css/style.css: estilos e responsividade
- js/app.js: menu mobile e comportamento demonstrativo do formulário
- assets/img/: ilustrações SVG locais

COMO EXECUTAR
1. Extraia o arquivo ZIP para uma pasta.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html no navegador.
4. Recomendado: use a extensão Live Server no VS Code e clique em "Go Live".

OBSERVAÇÕES
- Não é necessário instalar dependências nem usar servidor backend.
- O formulário é apenas demonstrativo: valida os campos e mostra uma mensagem, mas não envia e-mail nem salva dados.
- Os textos e dados de contato são fictícios e podem ser editados nos arquivos HTML.
- A fonte externa usa Google Fonts; sem internet, o navegador utiliza fontes alternativas.
